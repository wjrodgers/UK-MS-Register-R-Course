# Introduction to R

Course materials for the one-day Introduction to R course.

## Getting started

### 1. Download the course files

Click:

**Code → Download ZIP**

Unzip the folder somewhere easy to find, such as your Documents folder.

### 2. Open the R project

Double-click:

`Intro_to_R.Rproj`

This will open the complete course project in RStudio.

### 3. Install the required packages

Run:

```r
install.packages(c(
  "tidyverse",
  "readxl",
  "janitor"
))
